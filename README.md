## 🚀 What I'm working on

### 🏢 CIAL Knowledge OS

**Offline-first enterprise AI knowledge system**

[Repository](https://github.com/adithya-a-labs/CIAL-Knowledge-OS-v1-dev)

Built as part of my work at Cochin International Airport, CIAL Knowledge OS is an on-prem enterprise knowledge platform designed around governed document repositories, authorization-aware retrieval, evidence selection, and local inference.

Some of the systems I worked on include:

* Hybrid dense + BM25 retrieval
* Reciprocal Rank Fusion and cross-encoder reranking
* Evidence selection and citation-linked answers
* Continuous document indexing and versioning
* Authorization-aware retrieval and source access
* PostgreSQL + Qdrant knowledge infrastructure
* Local LLM inference with Ollama
* OCR and multi-format document processing
* Evaluation pipelines and retrieval benchmarking
* Admin monitoring, search, notes, summaries, exports, and knowledge workspaces

**Stack:**
`Python` · `FastAPI` · `React` · `TypeScript` · `PostgreSQL` · `Qdrant` · `Docker` · `BGE-M3` · `Ollama`

### 🔎 Multi-Document RAG

**Merged into `vmDeshpande/ai-agent-automation`**

[View merged PR #143](https://github.com/vmDeshpande/ai-agent-automation/pull/143)

Extended an existing RAG system from single-document retrieval to multi-document reasoning.

Implemented:

* Multi-document document selection
* Cross-document retrieval
* Balanced retrieval across documents
* Context budgeting
* Source attribution
* Chunk deduplication
* Processing progress tracking
* Fault-tolerant document processing
* Retrieval scalability safeguards

During review, the maintainer raised concerns about loading and scoring too many chunks across large documents. I reworked the retrieval strategy with bounded loading and global scoring limits, after which the contribution was approved and merged.
