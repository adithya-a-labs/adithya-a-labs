## 🚀 Selected Work

### 🏢 CIAL Knowledge OS

**Offline-first enterprise AI knowledge platform**
[Repository](https://github.com/adithya-a-labs/CIAL-Knowledge-OS-v1-dev)

Built as part of my work at Cochin International Airport.

* Hybrid dense + BM25 retrieval with RRF and cross-encoder reranking
* Authorization-aware retrieval, evidence selection, and citation-linked answers
* Continuous indexing, document versioning, OCR, local inference, evaluation, and admin tooling

`FastAPI` · `React` · `TypeScript` · `PostgreSQL` · `Qdrant` · `Docker` · `Ollama`

**AI-powered learning and knowledge extraction platform**
[Repository](https://github.com/adithya-a-labs/Carousel-Brain)

Built a full-stack AI workflow for turning unstructured learning material into summaries, concepts, action plans, resources, and structured insights.

`React` · `Node.js` · `Express.js` · `Supabase` · `OCR` · `LLM APIs`

### 🤖 Gesture-Controlled Robotic Arm

**Computer vision + inverse kinematics + embedded control**

Built a real-time control pipeline using webcam-based pose tracking, inverse kinematics, servo mapping, and microcontroller communication.

`Python` · `OpenCV` · `MediaPipe` · `NumPy` · `ESP32`
